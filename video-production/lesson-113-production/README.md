# Lesson 113 — three text-led instructional videos

Separate production implementation of the **approved** Module 5 prototype.
The original `../module-5-style-test/` is preserved unchanged. Same Noto Sans,
graphite/warm-white palette, restrained lavender/mint/blue/sand, masked title
entrances, cubic-bezier timing, original folder motif and precise schematic tracks.

## Package

| Composition | Topic | Duration |
| --- | --- | --- |
| `SourceOrganization` | Working folders, copies, naming, rights and approved versions | 46 s |
| `ProjectImport` | New project, workspace, import, ratio and first clip | 47 s |
| `TimelineReopen` | Sequence, duration, seams, zoom, reopening and source links | 54 s |

All: 1920×1080, 30 FPS, H.264/yuv420p with AAC **sound effects only**. There is
no narrator, music or spoken-subtitle track. Three smaller 960×540 previews use
the same exact frame timings. Durations follow concise text and reading time,
not the old planned 110-second narration storyboards.

Outputs:

- `out/final/m5-l13-v1-source-organization.mp4`
- `out/final/m5-l13-v2-project-import.mp4`
- `out/final/m5-l13-v3-timeline-reopen.mp4`
- Matching `out/previews/*-preview.mp4`
- `transcripts/*.ru.md`: three accessible reading equivalents, not invented speech
- `out/qa/previews/`: one actual rendered frame from every scene
- `out/technical-validation.json`: metadata, decode, audio peaks and SFX synchronization
- `out/logs/`: render logs, separate from source

## Preview in Studio

```sh
cd video-production/lesson-113-production
# Use the existing NVM Node installation if Node is not already on PATH.
npm run dev -- --port=3113
```

Open:

- http://localhost:3113/SourceOrganization
- http://localhost:3113/ProjectImport
- http://localhost:3113/TimelineReopen

Press Space to play/pause. Click the timecode to enter a frame. In the composition
props editor set **`muteSfx: true`** to mute all effects, or adjust **`sfxVolume`**
(default 0.4, clamped to 0–1). Audio cues never carry required teaching meaning.

## Source and reuse

- `content/videos.json`: scene title, one instruction, short note, duration,
  visual type, action marker and longer text alternative. Add new scene data
  using the existing visual vocabulary; no animation-engine rewrite is needed.
- `src/primitives.tsx`: approved typography entrances, panel, file cursor,
  reading captions, step markers and persistent illustration disclaimer.
- `src/visuals.tsx`: reusable folder explorer, file cards, workspace and timeline
  tracks. All geometry is schematic, not a copy of CapCut's interface.
- `src/Tutorial.tsx`: scene sequencing, transitions and frame-exact SFX track.
- `src/tokens.ts`, `src/fonts.ts`: copied approved tokens and local font loading.
- `src/Root.tsx`: three editable registrations. `calculateTutorialMetadata` derives
  each duration from scene data (seconds × 30); keep the displayed defaults consistent.
- Future approved narration/captions get separate tracks at the marked integration
  point. Do not reuse old narration timings or present these transcripts as speech.

```sh
python3 -B scripts/prepare_package.py   # deterministic original SFX, cues, transcripts
npm run lint                           # Remotion ESLint + TypeScript
npm run render:previews                 # inspect every scene first
python3 -B scripts/extract_frames.py
# After real frame inspection, out/qa/frame-review.json records the reviewed scenes.
npm run render:finals
npm run verify                         # installed ffprobe/FFmpeg, complete decode + SFX correlation
```

Final rendering is intentionally gated on preview frame review. Output/cache
folders are ignored. `npm ci` installs only this isolated project's pinned
Remotion 4.0.540 toolchain; no application dependencies are modified. Rendering
uses Remotion's bundled browser, with two concurrent frames by default.
`REMOTION_CONCURRENCY=4` uses at most four render tabs on this eight-core VM;
reduce it if memory is constrained.

## Sound provenance

Five original, reproducible PCM16/48 kHz mono effects are generated by Python's
standard library: a soft click, filtered-noise whoosh, damped pop, soft drop and
gentle two-note completion cue. No external sample, paid API, pretrained model,
voice imitation, music or copyrighted pack is used. See `content/sfx-provenance.json`
for exact checksums, duration and method, and `content/sfx-cues.json` for frame indices.

Cue frame indices are derived from the same `actionAt` markers that drive cursor
hits/visual actions. Whooshes mark scene entrances. Gains are restrained, with
source peaks bounded and actual AAC outputs checked for clipping. The verifier
correlates every decoded cue against its generated source at the expected frame,
rather than assuming that JSX timing proves output synchronization.

## Educational provenance and limitations

Based only on the existing lesson 13 source in
`courses/management/media_module_5.json`, its three approved storyboard purposes,
and the existing original F1 illustrations. Package-local provenance records the
source checksums. The course's asset manifest and lesson content remain untouched.

The lesson's actual five folders (`sources`, `audio`, `captions`, `exports`, `notes`)
replace the prototype's simplified four categories **without changing its design**.
The F1 project is fictional; no measured savings or university outcomes are claimed.

**Every interface is persistently labeled «Схема интерфейса · не запись CapCut».**
No CapCut screen recording, exact button location, proprietary project extension,
real import, successful application save or cloud backup is fabricated. Saving,
reopening and relinking must be checked in the viewer's installed version/OS.
The videos teach the workflow and conceptual checks; they do not replace a
version-verified screen recording. A rights-check table is a template, never a
fabricated permission record. The SVG illustrations are original educational
diagrams; displayed PNG filenames are examples, not claims that PNGs exist.

Fonts retain Noto SIL OFL notices under `public/fonts/`. The two original F1
SVGs are copied without modification and their provenance is recorded. No Silero
or ElevenLabs audio is used. Remotion organizational licensing remains separate
from original SFX/font rights; review it before production automation.

Nothing is uploaded/attached to lesson 113. No courses, accounts, SQLite,
application files, permissions, certificates, original prototype or prior assets
are modified. No commit, push, publication or deployment is performed.

The optional render-script `--resume` flag checks completed output metadata only;
use it only after confirming the content/visual source is unchanged. Normal
preview/final commands render from the current source.
