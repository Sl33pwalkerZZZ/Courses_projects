# Проект и импорт

Текстовый эквивалент видео без диктора, не расшифровка речи и не субтитры.

Урок 113. Ф1 — вымышленный учебный проект. Все интерфейсы — схемы, не запись CapCut. Звуковые сигналы не несут обязательной учебной информации.

## 1. 00:00–00:08 — Создайте обычный проект

В CapCut Desktop найдите создание нового проекта.

Имя: F1_horizontal_v01. Расположение элементов зависит от версии и ОС.

**Подробнее:** Назовите его F1_horizontal_v01. Подписи и расположение элементов зависят от версии и ОС.

**На иллюстрации:** Показана абстрактная карточка проекта, а не настоящий экран CapCut. Не подразумевается готовый шаблон.

## 2. 00:08–00:16 — Три области — три задачи

Библиотека → предпросмотр → таймлайн.

Выбираем материал, смотрим кадр, задаём время. Свойства зависят от выделения.

**Подробнее:** Выбираем материал, смотрим текущий кадр, задаём время. Свойства зависят от выделенного объекта.

**На иллюстрации:** Схема показывает библиотеку слева, предпросмотр справа и шкалу времени снизу. Это объяснение функций, не карта конкретной версии интерфейса.

## 3. 00:16–00:24 — Импорт — ещё не монтаж

Выберите «Импорт» и подготовленные файлы.

Дождитесь миниатюр. Просмотрите изображение и прослушайте звук до монтажа.

**Подробнее:** Дождитесь миниатюр. Просмотрите изображение и прослушайте звук до размещения на таймлайне.

**На иллюстрации:** Карточки перемещаются из рабочей папки в библиотеку. Таймлайн пока пуст; импорт не меняет порядок сцен автоматически.

## 4. 00:24–00:32 — Определите форму кадра

Для основной версии Ф1 выберите 16:9.

9:16 адаптируем отдельно. Пропорции — не число пикселей.

**Подробнее:** 9:16 — отдельная адаптация. Пропорции не равны числу пикселей. Не обрезайте пометку «Учебный пример».

**На иллюстрации:** Широкий и вертикальный холсты показаны рядом. Широкий вариант выбран для примера; схема сохраняет учебную маркировку.

## 5. 00:32–00:39 — Не путайте три сущности

Исходник ≠ проект ≠ экспорт.

Проект описывает монтаж. MP4 предназначен для просмотра.

**Подробнее:** Проект описывает монтаж. Переименование проекта не переименовывает исходники. MP4 — файл для просмотра.

**На иллюстрации:** Три разные карточки связывают оригинальный материал, редактируемую сборку и результат экспорта. Экспорт не является резервной копией проекта.

## 6. 00:39–00:47 — Добавьте первый кадр

Перенесите изображение на начало видеодорожки.

Поставьте курсор внутри клипа: в предпросмотре должен быть тот же материал.

**Подробнее:** Поставьте курсор внутри клипа. В предпросмотре должен быть тот же материал. Далее следуйте кадровому плану.

**На иллюстрации:** Одна и та же схема листа видна в библиотеке, первом клипе и предпросмотре. Это условная демонстрация, не выполненный импорт в настоящий CapCut.

Выполните проверку на своей версии редактора. Схема не подтверждает настоящее сохранение или импорт и не обещает облачное резервирование.
