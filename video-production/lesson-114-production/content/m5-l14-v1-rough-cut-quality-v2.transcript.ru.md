# m5-l14-v1-rough-cut-quality-v2

Учебная схема, не запись CapCut Desktop. Ф1 — вымышленный пример. Без диктора и речевого примера.

## 0–7с: Сначала — черновая сборка

Выберите только подготовленные материалы. Ф1: лист → проверка → сборка → блокнот.

Библиотека условных исходников показана до размещения. Импорт и размещение — разные действия.

## 7–15с: Сократите лишнее окончание

Выберите видеоклип и измените его край. Исходник не удаляется. Здесь — схема записи действия.

Условный временной клип сокращается с 12до 10секунд; это не неподвижная фотография.

## 15–23с: Разделите перед паузой и после

Две границы выделяют лишнюю середину. Части на дорожке — не новые файлы.

Клип 10с разделён в 3и 5с: действие 3с, пауза 2с, действие 5с.

## 23–31с: Удалите только лишний фрагмент

Проверьте выделение и оставшийся разрыв. Поведение соседей зависит от режима редактора.

Исчезает только фрагмент 3–5с; видимый разрыв пока остаётся.

## 31–38с: Закройте разрыв осознанно

Сдвиньте правую часть к левой. Проверьте звук отдельно: он не должен сдвинуться случайно.

Правая часть вручную сдвигается с 5сна 3с, получается 8с без пустоты.

## 38–46с: Верните понятный порядок

Для картинки меняют время показа. Лист → проверка → сборка → блокнот.

Возврат к неподвижным схемам Ф 1: сначала исправляется порядок, затем лист 5с→7с. Не выдавать их за снятое действие.

## 46–54с: Проверьте стыки до эффектов

Посмотрите обычный темп и смысл перехода. Нет пустого кадра; важное условие остаётся заметным.

Курсор проходит стык листа и проверки; предпросмотр меняется на границе. Эффекты не добавляются.
