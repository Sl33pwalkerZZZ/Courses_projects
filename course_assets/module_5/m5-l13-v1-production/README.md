## Озвучка

Существующий локальный `v5_cis_base_nostress`, `ru_roman`, CPU, 24 кГц,
моно PCM16. Проверен SHA-256 локального checkpoint из ранее проверенной
CIS Base цепочки происхождения. Источники модели/лицензии и контрольные суммы
записаны в narration-provenance.json. Другие модели не скачивались.
Использована существующая функция assemble из Module 4 без изменения её файла.
Темп 94%, межабзацные паузы 650 мс; без растяжения и изменения высоты тона.
Выборочные знаки ударения не меняют слова; требуется прослушивание автора.

Длительность: **59.2125 с**, план **110 с**, разница **−50.7875 с**.
Это речь с короткими межабзацными паузами, не готовая дорожка монтажа.
Не дополнять искусственной речью и не растягивать ради плана. Записать реальные
действия, оставить разумные паузы на чтение, затем согласовать итоговую длину.
Ни сегментные границы синтеза, ни план кадров не являются готовыми субтитрами.

Прослушать из корня проекта:

```sh
aplay course_assets/module_5/m5-l13-v1-production/narration-preview.wav
```

Проверить пакет без синтеза:

```sh
python3 -B course_assets/module_5/m5-l13-v1-production/validate_package.py
```

Для проверки существующего локального WAV дополнительно:

```sh
python3 -B course_assets/module_5/m5-l13-v1-production/validate_package.py --require-preview
```

Без WAV проверяются исходники и метаданные; проверка звука явно пропускается.
Helper `course_assets/module_4/voice_candidates/prepare_roman_module4.py` и его
`LICENSE_CIS` включены в Git. Это зависимость только офлайн-синтеза, не Django
или React. Хеш helper проверяется по сохранённому provenance. Локальные веса и
PyTorch не включены в Git; источник, хеш checkpoint и версия PyTorch записаны в
narration-provenance.json. Используйте указанное изолированное CPU-окружение;
не устанавливайте зависимости синтеза в Django .venv.

Повторный синтез — только в отдельный локальный каталог, без изменения исходников:

```sh
.local-silero-eval/venv/bin/python -B course_assets/module_5/m5-l13-v1-production/generate_preview.py --output-dir .local-silero-eval/m5-l13-v1-preview
```

Для воспроизведения синтеза скрипт generate_preview.py использует существующее
изолированное окружение `.local-silero-eval/venv/bin/python`; он намеренно
отказывается перезаписывать уже созданный WAV/метаданные. Требуются существующий
checkpoint с указанным хешем и сохранённый Module 4 helper. Django .venv не нужен.
При выполнении PyTorch предупредил об отсутствии необязательного NumPy и
устаревшем escape внутри checkpoint; синтез успешно завершился без установки пакетов.
