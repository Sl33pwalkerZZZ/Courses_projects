# Пять сцен: Ф1 — организация исходников

План: 110 секунд, не фактические таймкоды. Исходные шесть кадров сохранены; сцена 5 объединяет проверку звука и итог.

## Сцена 1: 0–12 с

Действие: Открыть подготовленную заметку с задачей ролика; выделить фразу про отсутствие расчёта эффекта.

Диктор: Готовим вымышленный пример «Вторая сторона листа». Сначала отберём материалы, а не будем импортировать всё подряд. Расчёт экономии в этом ролике не заявляется.

Проверка: Пометка об учебном характере читается; нет реальных названий университета.

## Сцена 2: 12–32 с

Действие: Показать создание sources, audio, captions, exports и notes; задержать кадр на получившейся структуре.

Диктор: Разделим исходники, звук, подписи, экспорт и заметки. Названия папок нужны нам для порядка. Это не обязательная структура CapCut.

Проверка: Все пять папок видны; никакая папка не выдаётся за настройку приложения.

## Сцена 3: 32–52 с

Действие: Скопировать учебные файлы в рабочую папку и переименовать только копии; оригиналы оставить без изменений.

Диктор: Копируем выбранные изображения и даём им понятные имена. Оригиналы сохраняем отдельно. По имени должно быть ясно, какой кадр мы используем.

Проверка: Оригиналы не перемещены и не перезаписаны; нет читаемых чужих документов.

## Сцена 4: 52–75 с

Действие: Добавить строки «автор», «источник», «разрешённое использование» и «обязательная атрибуция» для демонстрационных файлов.

Диктор: Для каждого источника фиксируем автора и условия использования. Ссылка и бесплатное скачивание сами по себе не подтверждают разрешение на распространение.

Проверка: Записи соответствуют фактически подготовленным материалам; нет выдуманного лицензионного одобрения.

## Сцена 5: 75–110 с

Действие: Прослушать короткий разрешённый отрывок, открыть учебный SRT как текст и показать связь с нужной сценой.

Диктор: Проверяем выбранную версию голоса и подписи. Старый экспериментальный файл с похожим названием не заменяет утверждённую запись.

Проверка: Звучит именно разрешённая запись; SRT не содержит чужой речи/данных.

Действие: По очереди выделить файл для первой и последней сцены; закрыть заметку без изменения исходников.

Диктор: Теперь каждому кадру соответствует известный материал. Неподтверждённые файлы не импортируем. Дальше создадим проект из этого проверенного набора.

Проверка: Выбранный набор соответствует общему Ф1-сценарию.
