## Выполненные технические проверки

1. UTF-8 JSON, ожидаемые названия и порядок; схема соответствует источникам
   модулей 3/4: верхние ключи `module`, `lessons`, поля урока `title`, `objectives`,
   `source_sections`, `text_content`.
2. Все 27 заголовков — уникальные отдельные абзацы своего урока, стоят в порядке
   `source_sections`, первый заголовок начинает текст. Обязательных оценочных
   структур нет; практика названа самостоятельной без оценки.
3. Полная читаемая Markdown-копия содержит все абзацы, цели, экранные действия,
   реплики и проверки из канонических JSON без потери текста.
4. Все девять раскадровок имеют непрерывные возрастающие плановые интервалы,
   три видео на каждый урок и отдельный якорь для каждой пары video/VTT.
5. Файлы и якоря между манифестом/раскадровкой/исходником совпадают. Нет
   предполагаемых DB lesson ID, внешних медиассылок или готовых фальшивых файлов.
6. Реальные чистые функции `mediaLessonSections` и `attachmentLayout` из React
   проверены через Node на этих исходниках: три набора по девять секционных
   моделей, по три inline-пары; без fallback и повторяющихся VTT-карточек.
   Объекты вложений существовали только в памяти для проверки контракта.
7. Нативный `frontend_reviewer` независимо выполнил read-only проверку этих
   артефактов и существующей логики представления. Подтверждённых блокеров не
   найдено; авторская проверка интерфейса/прав/реальной записи остаётся обязательной.

## Что человек должен проверить до утверждения

| Область | Что остаётся проверить |
| --- | --- |
| Педагогика | Автор подтверждает полноту, понятность и единый Ф1; 45 секунд — учебный ориентир, не требование площадки |
| CapCut Desktop | Выбрать реальную ОС, версию, язык и аккаунт; пройти все шаги в приложении; сверить Import, Split, Ratio, сохранение/дублирование и Export |
| Субтитры | Официальные руководства показывают разные Captions/Text пути; подтвердить доступный импорт SRT и наличие/условия Auto Captions в записываемой сборке |
| Экспорт | Проверить реальный MP4 через ffprobe; не предполагать доступность управления AAC/yuv420p/профилем в меню CapCut |
| Речь | Утвердить формулировки, произношение Ф1 и названий, выбранную запись/голос и право её распространения |
| Видеоряд | Сделать настоящие записи экрана; проверить отсутствие личных данных/уведомлений, читаемость интерфейса на телефоне и соответствие действий диктору |
| Тайминг | Уточнить плановые длительности после съёмки, синхронизировать VTT с фактической речью, проверить границы и отсутствие перекрытий |
| Права | Подтвердить графику, шрифты, запись экрана, звук и требуемую атрибуцию; учебное использование не объявляется автоматическим разрешением |
| Контрпримеры | Не выдавать учебную ошибку/технический клип за реальный результат ИИ или документальный факт проекта |
